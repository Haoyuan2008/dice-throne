# 王权骰铸 · Dice Throne 联机对战

一款基于《王权骰铸》（Dice Throne）核心玩法的**网页联机对战游戏**。掷出英雄专属骰子、锁定骰面、凑出强力组合削减对手生命值，支持创建房间号邀请好友联机，也可添加人机陪练。

> 玩法原型参考桌游《王权骰铸》（Dice Throne，Roxley / 原石桌游）。本仓库为个人学习与练习项目。

---

## ✨ 功能特性

- **掷骰对战**：每回合最多 3 次掷骰，锁定骰面凑组合，转化为伤害。
- **房间联机**：创建 6 位房间号，好友输入相同号码即可加入同局（2–6 人）。
- **人机陪练**：房主可添加人机，AI 自动掷骰出招。
- **成员管理**：房主可移除其他成员（不能移除自己，仅对战前可移除）。
- **十六英雄**：第一季 + 第二季共 16 名英雄，各具专属骰面与风格。

### 组合与伤害

| 组合 | 条件 | 伤害 |
|------|------|------|
| 五条 · 至高王权 | 五个相同骰面 | 50 |
| 四条 · 王座之约 | 四个相同骰面 | 25 |
| 葫芦 · 宫廷联姻 | 三条 + 一对 | 20 |
| 三条 · 骑士之誓 | 三个相同骰面 | 15 |
| 两对 · 双翼 | 两个对子 | 10 |
| 一对 · 起步 | 两个相同骰面 | 5 |

### 十六英雄

- **第一季**：野蛮人、月精灵、火法师、暗影盗贼、武僧、圣武士、忍者、树人
- **第二季**：枪手、武士、战术家、女猎手、诅咒海盗、工匠、炽天使、吸血鬼领主

## 🚀 本地运行

这是一个纯静态网页项目，**无需安装依赖、无需构建**。

1. 克隆或下载本仓库到本地。
2. 直接用浏览器打开 `index.html` 即可游玩。

> 注意：联机功能需要联网，并依赖云服务后端（见下文「联机后端说明」）。
> 若仅双击 `index.html`，请确保 `config.js` 与 `assets/` 在同一目录下。

---

## 🔌 联机后端说明

游戏的房间联机功能由 **WorkBuddy 云服务**提供（数据库 + 后端）。前端通过 CDN 加载 SDK 并读取 `config.js` 中的配置连接云端。

- `config.js` 内的 `publishableKey` 是**前端公开密钥**，本身不携带权限，云端通过网页来源（Origin）精确匹配做安全校验，放入公开仓库不会泄露权限。
- 请勿在仓库中提交任何**服务端私有密钥**。

如需重新绑定自己的云环境，替换 `config.js` 中的 `endpoint` 与 `publishableKey` 即可。

## 🛠️ 如何继续开发

### 调整核心参数（无需懂代码也能改）

所有可调参数集中在 `index.html` 脚本区的顶部，便于边玩边改：

| 配置项 | 位置 | 说明 |
|--------|------|------|
| `HEROES` | index.html 脚本区 | 16 名英雄（名称、骰面、难度） |
| `COMBOS` | index.html 脚本区 | 组合名称、条件、伤害值 |
| `MAX_ROLLS` | index.html 脚本区 | 每回合掷骰次数 |
| `DICE_COUNT` | index.html 脚本区 | 骰子数量 |
| `MAX_HP` | index.html 脚本区 | 初始生命值 |

### 常见迭代方向

- **加新英雄**：在 `HEROES` 数组新增一项即可，选择界面会自动展示。
- **调 AI 智能度**：修改 `aiTakeTurn` 函数中的掷骰与目标选择逻辑。
- **改组合规则**：修改 `calcCombo` 与 `COMBOS` 数组。
- **换背景/主题**：替换 `assets/` 下的背景图，并更新 `index.html` 中 `body::before` 的图片路径。

## 📦 部署上线

本项目是静态站点，可部署到任意静态托管服务：

- **GitHub Pages**：仓库 Settings → Pages → 选择分支与目录，即可获得在线链接。
- **WorkBuddy 发布**：在 WorkBuddy 中点击「发布」，自动生成在线分享链接。

> 联机功能需要部署后的域名与云服务后端 Origin 匹配；若更换部署域名，需同步更新云服务的域名授权。
